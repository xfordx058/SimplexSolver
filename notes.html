Notes & Quick Tips

Formatting examples

  • Objective: write as max z = 120x + 100y or just 120x + 100y.
  • Constraints: single-letter variable names (x, y, z). Example: 2x + 3y <= 24.
  • RHS must be a number; avoid expressions like 2 * 12 (use the evaluated number).

Common issues

  1. Missing sign in the objective ensure each term is numeric (e.g., 1.5x instead of x only).
  2. Two-letter variable names are not supported by the simple parser (use x, y, z).
  3. Problems requiring two-phase Simplex (artificial variables) aren't handled yet.

Tips for teaching

Use the sample data CSV and the PDF guide to illustrate the same problem step-by-step in class — the slide deck shows examples and solutions too.
